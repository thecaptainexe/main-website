# Contributing

Thanks for taking the time to contribute.

## Expectations

- Keep changes focused and easy to review.
- Do not commit secrets, credentials, or local environment files.
- Do not submit malicious or harmful code.
- Test changes before opening a pull request.
- Follow the existing project conventions and keep the homepage experience stable.

## Local development

```bash
npm install
npm run dev
```

## Pull requests

Keep PRs focused on one purpose and make sure the project still builds before submitting.
